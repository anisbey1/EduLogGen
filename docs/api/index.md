# API reference

EduLogGen exposes a small public surface in `0.1.0`. Subpackages define
namespaces for upcoming features; their concrete APIs will be documented here as
they land.

| Module | Purpose |
| ------ | ------- |
| [`eduloggen`](eduloggen.md) | Package root and version metadata |
| [`eduloggen.cli`](cli.md) | Command-line entry point |
| `eduloggen.ingestion` | Log loading and normalization (planned) |
| `eduloggen.analysis` | Session and statistical analysis (planned) |
| `eduloggen.generators` | Synthetic generators (planned) |
| `eduloggen.validation` | Validation and benchmarking (planned) |
| `eduloggen.visualization` | Visualization helpers (planned) |

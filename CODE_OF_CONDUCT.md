# Code of conduct

EduLogGen follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and do not
harass or discriminate against anyone. This applies to issues, pull
requests, discussions, and any other project space.

Report unacceptable behaviour privately to the maintainers through GitHub
(**Security → Report a vulnerability** works for confidential reports). All
reports are reviewed and handled confidentially.

# Security policy

## Supported versions

Security fixes are made for the latest minor release only.

## Reporting a vulnerability

Please do **not** open a public issue for security problems, including
anything that could expose information from real learner logs (for example
a way to recover source identifiers or rare sequences from synthetic output).

Report privately through GitHub: **Security → Report a vulnerability** on
the repository page. You will get an acknowledgement within 7 days and a
plan or fix within 30 days where possible.
